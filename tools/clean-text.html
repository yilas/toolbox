Ce que la page protège et transforme
Le nettoyage protège les blocs fenced Markdown (backticks ou tildes), le code indenté, le code inline et les URL avant toute transformation. Les deux espaces finaux servant de hard line break Markdown sont conservés, ainsi que l'indentation. Le linter ignore également ces zones techniques. La page fonctionne sans bibliothèque externe et peut être ouverte directement depuis le système de fichiers, même hors ligne.
