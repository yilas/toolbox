✳ Scratchpad

Un coin pour tes commandes, idées, liens et bouts de code.

Personnaliser les catégories

Change le nom, la couleur et l’ordre de tes catégories (⠿ pour glisser, ↑/↓ pour déplacer). « À classer » reste disponible pour accueillir les notes d'une catégorie supprimée.

🗑 Corbeille

Restauration possible pendant 7 jours. Les blocs temporaires ne survivent pas à la fin de la session.

Aide Scratchpad

Appuie sur ? depuis la page pour afficher cette aide ; Échap pour la fermer.

Notes et organisation

  • Les nouvelles notes sont persistantes par défaut dans IndexedDB. Décoche « 📌 Persistant » pour une note temporaire et choisir éventuellement une expiration (1 min à 24 h).
  • Choisis le format Compact, Standard ou Large sur chaque note.
  • Classe les notes par catégories colorées et tags. Le bouton « ⚙ Gérer les catégories » permet de personnaliser les catégories.
  • Déplace les cartes avec la poignée ⠿ ou les flèches ↑/↓, sans recherche ni filtre actifs.
  • Les notes supprimées peuvent être restaurées depuis la corbeille pendant 7 jours.

Copie et stockage

  • Copie une note ou toutes les notes, colle le presse-papiers dans une nouvelle carte, ou utilise l'import/export JSON.
  • Le dernier bloc consulté est mémorisé pour le retrouver après un rechargement ou dans un autre onglet lorsqu'il est disponible.
  • Les données restent dans le navigateur sans synchronisation. ⚠️ Stockage local non chiffré : ne conserve pas de tokens sensibles.

Raccourcis

  • ? Ouvrir l'aide · Échap Fermer
  • Ctrl/⌘ + Entrée Nouveau bloc · Ctrl/⌘ + K Rechercher
  • Ctrl/⌘ + Maj + V Créer un bloc du presse-papiers (hors éditeur)
  • Ctrl/⌘ + Maj + C Copier le bloc actif · Alt + ↑/↓ Déplacer le bloc actif
